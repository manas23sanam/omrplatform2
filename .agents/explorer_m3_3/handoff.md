## 2. Logic Chain

1. **Requirement Mapping for F20 (Dedicated "Mock Tests & Improvement" Page):**
   - **Original Request (R3/AC)** requires a dedicated page specifically for accessing AI-configured mock tests and targeted improvement exercises.
   - The existing `MockTestsImprovement.tsx` fulfills the foundational UI shell, but can be significantly enhanced with:
     - Clear tab/filter separation between **AI-Configured Mock Tests** (generated by AI Learning GPS based on recent OMR mistake patterns) and **Teacher-Assigned Remediation Drills** (curated by teachers like Dr. S. K. Verma).
     - Subject filters (All, Physics, Chemistry, Mathematics) and Difficulty filters (All, Easy, Medium, Hard).
     - Rich weak-topics checklist controls: Direct "Launch Practice Quiz" CTA on every weak topic directing to `/student/practice/${topic.id}`, dynamic status selector (`not_started` | `studying` | `ready` | `mastered`), and mistake count urgency tags.

2. **Requirement Mapping for F21 (Interactive Practice & Verification Quiz Session):**
   - **Original Request (R3/AC)** and **PROJECT.md (F21)** require an interactive practice and concept verification quiz session featuring:
     - Multi-question MCQ quiz with 4 options per question (A, B, C, D).
     - Active timer (countdown or elapsed time with visual warnings).
     - Option selection with active highlight states.
     - Immediate grading & explanations (instant feedback showing correct option, student option, and detailed AI rationale/solution steps).
     - Score calculation (percentage accuracy and correct/incorrect summary).
     - Store dispatch of earned XP (`+150 XP`) and status update to `LearningStoreContext`.
   - The current `Practice.tsx` lacks these features and must be replaced/upgraded into a full-featured `PracticeSession.tsx` (or upgraded `Practice.tsx`).

3. **Domain Integration & Mock Question Data:**
   - When a student opens `/student/practice/:topicId`, the quiz component must resolve `:topicId`:
     - If `:topicId` matches a `weakTopic.id` (e.g., `topic-rotational-friction`, `topic-le-chatelier-inert`, `topic-definite-integral-kings`, `topic-lenz-law-flux`, `topic-organic-sn1-sn2`), load the dedicated 5-question high-yield question pack for that concept.
     - If `:topicId` matches an `assignedTest.id` (e.g., `assign-01`, `assign-02`, etc.), load the corresponding subject practice pack.
     - Provide a default JEE Advanced high-yield question bank if an unmatched ID is passed.
   - On quiz completion, calling `completePracticeQuiz(topicId, finalScorePercentage, earnedXp)` seamlessly updates:
     - User XP (`currentUser.xp += earnedXp`)
     - Topic status (`mastered` if score >= 80%, `studying` otherwise)
     - Cohort Leaderboard (`leaderboard` XP increment and dynamic rank re-sorting)
     - LocalStorage persistence across page reloads.

## 3. Caveats

1. **Routing Path Cohesion**:
   - `src/App.tsx` currently imports `import { Practice } from './pages/Practice'`. The upgraded practice session can either replace `src/pages/Practice.tsx` or live in `src/pages/student/PracticeSession.tsx` with appropriate re-export or route binding in `App.tsx`.
2. **Persistence Lifecycle**:
   - Because `LearningStoreContext` persists to `localStorage`, tests must be able to reset state via `resetToDefaults()` or work reliably with freshly initialized mock data.
3. **No External Backend Needed**:
   - All question banks, timer animations, grading engines, and XP ledgers are completely self-contained in frontend React state and mock repositories, enabling instantaneous responsiveness without backend dependencies.

#### F21: Interactive `PracticeSession.tsx` (`/student/practice/:topicId`)
- **State Management**:
  ```ts
  interface PracticeQuizState {
    topicId: string;
    topicName: string;
    subject: SubjectName;
    questions: PracticeQuestion[];
    currentQuestionIndex: number;
    selectedAnswers: Record<number, number>; // questionIdx -> selectedOptionIdx (0..3)
    checkedAnswers: Record<number, boolean>;  // questionIdx -> boolean
    timeRemainingSeconds: number;             // e.g. 600s (10 min)
    isTimerRunning: boolean;
    isSubmitted: boolean;
    finalScore: number;                       // 0..100%
    earnedXp: number;
    instantCheckMode: boolean;                // Check immediately per question vs submit all at end
  }
  ```
- **Quiz Workflow**:
  1. **Briefing Header**: Topic title, subject pill, XP bounty badge (`+150 XP`), and link back to `/student/mock-tests`.
  2. **Active Quiz Controls**:
     - Question indicator (`Question 2 of 5`).
     - Progress bar (`40% Complete`).
     - Animated Timer (countdown with red pulse when `< 60s`).
     - Instant Feedback Toggle ("Instant Check" vs "Simulated Exam").
  3. **MCQ Question Card**:
     - Question prompt with equations and scenario details.
     - 4 Option buttons (A, B, C, D):
       - Default state: Clean border, hover transition.
       - Selected state: Indigo ring, background tint.
       - Checked Correct: Emerald ring, green background, checkmark icon.
       - Checked Wrong: Red ring, red background, cross icon, correct option highlighted in green.
     - Detailed Explanation Accordion: Appears immediately upon checking or after submission, detailing the exact derivation, concept rationale, and why alternative options are incorrect.
  4. **Question Navigator Drawer**:
     - Palette of question numbers (1, 2, 3, 4, 5...) with status indicators (Current, Answered, Unanswered).
  5. **Submission & Results Screen**:
     - Score Gauge (% score, e.g. 80% or 100%).
     - XP Award Card with celebratory animation and total XP counter.
     - Mastery Status Banner:
       - If Score >= 80%: "Mastery Achieved! Topic marked as Mastered."
       - If Score < 80%: "Practice Complete. Marked as Studying. Review solutions and try again."
     - Solution Review Mode: Scrollable list of all questions with chosen answers, correct answers, and AI explanations.
     - Navigation buttons: "Return to Mock Tests" (`/student/mock-tests`) and "Retake Quiz".
  6. **Store Dispatch**:
     - Executes `completePracticeQuiz(topicId, scorePercentage, earnedXp)` upon test submission, ensuring XP increment and leaderboard update.
